# Canonical news output and GlobeNewswire transport

Scope: canonical news output envelope only; unchanged Luna, schemas, quality
validation, one shared repair allowance, token limits, budget, routing and trading.
Legacy/final-review completion paths retain their prior response format.

Evidence: production quality/review failures included expected_value at position
0 and extra_data after complete objects. Do not salvage the first object. An
isolated prior approved test validated two forced-function schema responses.
That small sample is not proof of long-term reliability or content quality.

The output function is never executed. Exactly one choice and named function,
no nonempty message content, valid finite JSON without duplicate keys and the
unchanged schema are mandatory. Independent editorial review still applies.
Budget checks and cost recording remain around each single transport request.
Bounded encrypted diagnostics can capture output arguments, never prompts,
reasoning or headers; existing expiry and sample quota remain unchanged.

GlobeNewswire production transport reproduced errno 101 at TCP connect, before
TLS/HTTP (0.119 seconds). DNS returns IPv4 and IPv6; lexical first-address
selection may choose unreachable IPv6. Prefer provider-published IPv4 for
GlobeNewswire only. No extra connection attempts, proxies, timeout increase or
retry change. Public-IP validation and TLS hostname verification are retained.
The same official feed succeeded in an isolated patched process: 37,619 bytes,
0.250 seconds. Other provider transport configuration is unchanged.

Deployment requires exact-commit CI/readiness, normal encrypted recovery backup,
health checks and existing rollback. No schema migration or replay. Validate
natural post-release calls and provider cycles; no synthetic public messages.
